# Jarvis Chess

Two front doors onto one chess core. Stockfish chooses and judges every move; a free OpenRouter
model only *explains* them (never asked for a move). Chess never touches LiveKit or Gemini.

| | Voice Mode | Classic Mode |
|---|---|---|
| Start | `chess --voice`, or “Jarvis, let's play chess” (Jarvis launches it and hangs up) | `chess` in Konsole |
| Input | voice only; the board ignores mouse and keyboard | mouse + keyboard, voice optional (**Listen**) |
| Opening | holographic board build-in | 14 s ASCII cinematic, then the board window |
| Needs Jarvis running | no | no |
| Voice stack | local faster-whisper → parser / OpenRouter → local Piper | same, optional |

## Install (Nobara 44)

```bash
cd /mnt/data/jarvis-voice-butler/jarvis_new
sudo dnf install -y stockfish          # strongly recommended; without it a weak built-in engine plays
uv sync --extra chess                  # python-chess, rich, textual, pyfiglet, httpx, websockets
uv pip install sherpa-onnx==1.13.8     # only if a `uv sync` removed it (it is not in pyproject)
./scripts/install-chess-command.sh     # symlinks ~/.local/bin/chess (warns if the name is taken; offers `jchess`)
cd frontend && pnpm install && pnpm build   # exports the board UI into shell/ui (chess.html)
chess --mic-test                       # checks whisper, Piper and the wake client
```

Optional: `OPENROUTER_API_KEY` (free models explain moves). Put it in `~/.jarvis/keys.env` (0600) or
run the setup wizard. Without it, template explanations cover everything.

## Run

```
chess                    # intro -> Classic Mode window
chess --no-intro         # straight to the board
chess --intro-only       # just the cinematic
chess --voice            # Voice Mode (hands-free)
chess --tui              # play inside the terminal, mouse works
chess --mic-test         # voice setup check
chess --resume           # load the last autosave
chess --fen "<FEN>" --level expert --colour black --time 10+0 --spectate
```

`JARVIS_NO_INTRO=1` or `--no-intro` disables the intro. `NO_COLOR` gives mono output.
Exit codes: 0 ok, 1 error, 2 usage, 3 missing dependency, 4 voice engine unavailable, 130 Ctrl+C.

## Ports and the window

* Games server: `ws://127.0.0.1:4320` (loopback only, Origin-checked). **The brief said 4318, but Jarvis's
  mic-uplink already owns TCP 4318**, so chess uses 4320 and serves the static board on 4321.
* If the Jarvis desktop shell is running *and* was built with the chess window, `chess` uses its
  `chess` Tauri window (`jarvis-shell chess`). Otherwise it opens a Brave/Chrome `--app` window on
  `http://127.0.0.1:4321/chess.html` (the lightweight chess-only shell: no LiveKit, wake client or agent).
* KDE Wayland focus-stealing prevention can keep a new window behind others. Fallback KWin rule:
  System Settings → Window Management → Window Rules → Add New → “Window class (application)” =
  `brave-browser` (or `jarvis-shell`), title contains “Chess” → **Force** “Focus stealing prevention: None”.

## Voice details

* Use **headphones**. Chess drops any transcript that overlaps its own speech (except “stop”), and there is an
  optional echo-energy gate (Settings → Echo gate) for speakers.
* “Hey Jarvis” always wins: chess goes deaf (Piper cut, clock paused, banner “JARVIS ACTIVE — chess listening
  paused”) and resumes 1.5 s after the call ends. Chess never mutes the wake client. After 10 minutes with no
  end-of-call signal it listens only for “resume chess” (or press Space).
* Whisper `base.en` int8 on CPU measures 0.5–0.8 s for a short move. The prompt is a short vocabulary list on
  purpose: spelling whole moves in the prompt made it echo them back.
* Spoken commands: `docs/chess/COMMANDS.md`. Keyboard: `docs/chess/KEYBOARD.md`
  (both generated by `scripts/gen_chess_docs.py`). Intro recording: `docs/chess/intro.cast`
  (`asciinema play docs/chess/intro.cast`).

## Layout

`src/games/` core (no livekit / google.genai imports; a test enforces it): `chess/` (state, engine,
voice_moves, commands, game, analysis, intents, commentary, chat, templates, saves, settings, intro/),
`voice/` (capture, vad, stt, tts, engine, wake_watch, mic_test), `server.py`, `app.py`, `cli.py`, `tui.py`.
Shared LiveKit-free audio helpers live in `src/audio_shared.py`; the wake-event broadcast in `src/wake_events.py`.
