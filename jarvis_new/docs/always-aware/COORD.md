## Interface contracts (agree here, change only via an entry in the board)

```python
# P2 -> others.  src/aware/gate.py
@dataclass
class Opportunity:  id: str; kind: str  # "code" | "file" | "web" | "other"
                    summary: str; evidence: dict; est_minutes: float
@dataclass
class GateResult:   passed: bool; stage_failed: str | None; reasons: list[str]
                    plan: "TakeoverPlan | None"   # only when passed
async def evaluate(opp: Opportunity) -> GateResult      # 4-stage gate, PLAN.md s3
# P2 -> P1.  src/aware/offers.py
async def maybe_offer(opp: Opportunity, gate: GateResult) -> "OfferOutcome"
# OfferOutcome: accepted | declined | deferred | suppressed(reason); handles
# rate limits, cooldowns, shadow mode, learning. Speaks via a callable P1 injects:
#   set_speaker(fn: Callable[[str], Awaitable[None]])

# P3.  src/aware/takeover.py   (shared plan/result types live in src/aware/types.py, owned by P2)
async def run(plan: TakeoverPlan, *, progress: Callable[[float | None, str], None]) -> TakeoverResult
# dispatches by plan.kind: "code" -> codejob, "file" -> fileedit (with undo journal),
# "web" -> brave_live.run (P4). Independent success verification, stuck policy, handback.
# P4.  src/aware/brave_live.py
async def run(plan: TakeoverPlan, *, progress) -> TakeoverResult
async def handback(run_id: str) -> None
# P4 uses src/aware/transactions.py (audit log) for EVERY send/submit/payment, incl. failures.
```

`src/aware/types.py` (TakeoverPlan, TakeoverResult, Opportunity re-export) is
created FIRST by P2 within its first few steps. Others import it; until it
exists, code against the contract above with local stubs.
